# Mishra Gym Planner — Android project

This is an Android Studio project wrapping the stylish Mishra Gym Planner UI in a native Android WebView shell.

- Application ID: com.mishragymplanner
- Target/Compile SDK: 36
- Version: 1.0
- Portrait orientation
- Offline UI with local storage for profile/progress

Open this folder in Android Studio and build:
Build > Generate App Bundle(s) > Generate Bundle(s)

The resulting `.aab` can be uploaded to Google Play Console after completing Play Console setup/testing requirements.
